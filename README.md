# bank_hw

Запуск демонстрации из корня проекта

```sh
python3 -m scripts.demo
python3 -m scripts.demo_day2
```

В Day 2 ставки передаются как доли единицы (`"0.10"` означает 10%).
PremiumAccount применяет лимит и фиксированную комиссию к каждому снятию.
Комиссия учитывается при проверке овердрафта. InvestmentAccount переводит
средства из свободного баланса в портфель через `invest()`. Прогноз
годового прироста возвращает сумму в валюте счёта.
