# bank_hw

Запуск демонстрации из корня проекта

```sh
python3 -m scripts.demo
python3 -m scripts.demo_day2
python3 -m scripts.demo_day3
python3 -m scripts.demo_day4
```

В Day 2 ставки передаются как доли единицы (`"0.10"` означает 10%).
PremiumAccount применяет лимит и фиксированную комиссию к каждому снятию.
Комиссия учитывается при проверке овердрафта. InvestmentAccount переводит
средства из свободного баланса в портфель через `invest()`. Прогноз
годового прироста возвращает сумму в валюте счёта.

В Day 3 банк блокирует клиента после трёх последовательных неудачных попыток
входа. С 00:00 до 05:00 по часам банка запрещены вход, регистрация, изменение
статуса счёта и операции со средствами. Поиск и отчёты доступны круглосуточно.
Закрытый счёт сохраняется в истории и сохраняет свой баланс. Общий баланс и
рейтинг формируются отдельно по каждой валюте и учитывают средства в портфелях.

В Day 4 больший числовой приоритет обрабатывается первым среди готовых
транзакций, а при равенстве действует порядок постановки в очередь. Внешний
перевод явно помечается типом `external` и по умолчанию стоит 1% от суммы.
Комиссия списывается в валюте отправителя сверх суммы перевода. Для конвертации
обработчик принимает словарь учебных курсов. При ночном запрете по умолчанию
разрешены три попытки с интервалом в час. Причины отказов сохраняются в истории
транзакции.
